# Steam Game Analyzer

Steam 프로필 URL이나 SteamID64를 입력하면 보유 게임, 누적 플레이시간, 장르별 플레이 성향을 확인할 수 있는 웹 앱입니다.

## 주요 기능

- **프로필 카드** · 프로필 사진, 닉네임, Steam 레벨, 가입 기간과 플레이한 게임 비율을 표시합니다.
- **라이브러리 요약** · 보유 게임 수, 총 플레이시간, 미실행 게임 수와 1시간 미만 플레이한 게임 수를 집계합니다.
- **플레이시간 상위 5개** · 가장 오래 플레이한 게임을 Steam 배너와 함께 보여줍니다.
- **장르별 플레이 성향** · Steam 상점의 장르를 기준으로 플레이시간을 집계합니다. 장르가 여러 개면 시간을 균등 배분합니다. 조회를 취소하거나 실패한 게임만 다시 조회할 수 있습니다.
- **전체 게임 목록** · 게임 배너, 이름, 플레이 상태와 시간을 표시합니다. 게임을 검색하거나 플레이 상태로 필터링하고 이름·플레이시간으로 정렬할 수 있습니다.
- **플레이시간 비교** · 내 플레이시간을 Steam 리뷰 작성자 중앙값과 비교합니다. 중앙값이 0보다 클 때 내 시간이 **2배 이상이면 초록색**, **0.5배 이하면 빨간색**으로 표시합니다. `조회 대기`를 누르면 진행 중인 요청 다음에 해당 게임을 조회합니다.

## 추가 기능 (예정)

- **안 해본 게임 추천** · 보유한 미실행 게임 중 내가 오래 플레이한 장르와 겹치는 게임을 최대 3개 추천하고, 각 게임의 추천 이유를 표시합니다.
- **남들과 유독 다르게 한 게임** · 리뷰 작성자 중앙값보다 오래 플레이한 게임을 모아 내 기록, 중앙값, 배수를 비교합니다. 표본이 적거나 중앙값이 너무 낮은 게임은 순위에서 제외합니다.
- **게임별 플레이시간 분포** · 라이브러리에서 게임을 선택하면 Steam 리뷰 작성자의 플레이시간 히스토그램을 펼쳐 볼 수 있습니다. 내 기록과 리뷰 중앙값을 같은 그래프에 표시합니다.
- **Steam 게임 검색** · 게임 이름으로 Steam 게임을 검색하고, 라이브러리에 없는 게임도 리뷰 작성자의 플레이시간 히스토그램을 확인할 수 있습니다.
- **개인별 예상 플레이타임** · 검색한 게임의 리뷰 플레이시간 분포와 내 장르별 플레이 기록을 비교해, 내가 해당 게임을 플레이할 것으로 예상되는 시간을 추정합니다.

## 데이터 출처와 집계 기준

- **Steam Web API**에서 공개 프로필, 라이브러리와 게임별 누적 플레이시간을 가져옵니다. 라이브러리를 조회하려면 Steam 프로필과 게임 세부 정보가 공개되어 있어야 합니다.
- **Steam 상점**에서 배너와 장르를 가져옵니다. 장르 정보가 없거나 아직 조회되지 않은 게임은 미분류로 표시합니다.
- 상위 5개의 **`global`**과 전체 목록의 **`대부분의 이용자들`**은 같은 값입니다. 게임별 최근 공개 Steam 리뷰를 최대 500건 조회한 뒤, 유효한 누적 플레이시간이 있는 작성자를 중복 없이 집계해 중앙값을 계산합니다. 표본이 짝수면 가운데 두 값의 평균을 사용합니다. 이 값은 최근 리뷰 작성자 표본을 기준으로 합니다.

## 로컬 실행

Python, Node.js, pnpm이 필요합니다. 아래 명령은 Windows PowerShell 기준입니다.

1. 프로젝트 루트에서 백엔드 의존성을 설치합니다.

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

2. 프로젝트 루트에 `.env` 파일을 만들고 Steam Web API 키를 설정합니다. `.env`는 Git 추적에서 제외됩니다.

   ```dotenv
   STEAM_API_KEY=여기에_발급받은_키
   ```

3. 같은 터미널에서 백엔드를 실행합니다.

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn api:app --reload
   ```

4. 프로젝트 루트에서 새 터미널을 열고 프론트엔드를 실행합니다.

   ```powershell
   cd frontend
   pnpm.cmd install --frozen-lockfile
   pnpm.cmd dev
   ```

5. 프론트엔드 터미널에 표시된 `Local` 주소(기본 `http://127.0.0.1:5173`)를 열고 Steam 프로필 URL 또는 SteamID64를 입력합니다. 백엔드 API 문서는 `http://127.0.0.1:8000/docs`에서 확인할 수 있습니다.

## 기술 스택과 검증

- 프론트엔드 · React, TypeScript, Vite
- 백엔드 · Python, FastAPI, Uvicorn, SQLite(장르 캐시)

프로젝트 루트에서 백엔드 테스트를 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -v
```

`frontend` 폴더에서 프론트엔드 타입 검사와 빌드를 실행합니다.

```powershell
pnpm.cmd build
```
