# Steam Game Analyzer

Steam 게임 플레이 기록을 기반으로 사용자의 게임 취향을 분석하고, 새로운 게임을 추천하는 웹서비스입니다.

## 프로젝트 개요

사용자의 Steam 게임 라이브러리와 플레이타임 데이터를 분석하여 게임 선호도를 파악하고, 이를 바탕으로 개인화된 게임 추천 및 예상 플레이타임을 제공하는 것을 목표로 합니다.

## 주요 기능 (예정)

- Steam 프로필 및 게임 라이브러리 정보 조회
- 게임별 플레이타임 및 장르 선호도 분석
- 사용자 취향에 따른 게임 추천
- 추천 게임의 예상 플레이타임 제공
- 분석 결과 시각화

## 개발 환경 (예정)

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python (Flask 또는 FastAPI)
- **API:** Steam Web API
- **Data Analysis:** pandas, NumPy, scikit-learn

※ 세부 기능 및 기술 스택은 개발 과정에서 변경될 수 있습니다.
